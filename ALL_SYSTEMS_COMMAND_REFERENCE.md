## 🧪 TROUBLESHOOTING

### **Command not found / ModuleNotFoundError**
Make sure you're in the correct directory and using the full path:
```powershell
# ✗ Wrong
cd C:\Users\kiers\Downloads ; python dynamicmf\lonk_xembra_unified.py

# ✓ Correct
cd C:\Users\kiers\Downloads\dynamicmf ; python lonk_xembra_unified.py
```

### **Emoji/Unicode not displaying**
Always include the encoding line:
```powershell
$env:PYTHONIOENCODING="utf-8"  # Must come FIRST
```

### **Tkinter not found**
xembra-xc GUI requires Tkinter (included in Python 3.8+):
```powershell
# Check if installed
python -m tkinter

# If missing, install via conda or use CLI instead
$env:PYTHONIOENCODING="utf-8" ; cd "C:\Users\kiers\xembra-xc\desktop-lonkworld" ; python xc_app_runtime.py --source LonkWorld.xc
```

### **Slow on first run**
First startup compiles XC bytecode. This is normal and only happens once.

### **Save file not found**
Check the expected location:
```powershell
Test-Path "$env:LOCALAPPDATA\LonkWorldXC\world.json"
```
