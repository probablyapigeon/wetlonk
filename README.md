## Overview

The Dynamic Lonk Civilization Simulator is a sophisticated game AI system that combines cutting-edge concepts from neuroscience, philosophy, machine learning, and game design into a unified architecture. It features genuinely novel systems rarely (if ever) implemented in published game AI.

### 🎯 Core Features

- **⭐ Weight-Space Programming** — Direct neural network editing (no gradient descent)
- **⭐ Autonomous Epistemology** — Each agent builds its own axioms; paradigm shifts on falsification
- **⭐ Composable Verbs** — Teaching creates new behaviors; knowledge transfers between agents
- **⭐ Inner Monologue** — Streaming thoughts tied to emotional state
- **⭐ Psi-Theta Dynamics** — Mathematical consciousness model grounded in neuroscience
- **⭐ Conversation Persistence** — Multi-turn dialogues that stale out and conclude
- **⭐ Religion & Culture** — Emergent belief systems and myth creation
- **⭐ Interpretable AI** — Fully inspectable neural networks (32→16→6)

## 🧠 The Five Pillars of Novelty

### 1. **Weight-Space Programming** (⭐⭐⭐⭐⭐)
Direct editing of neural network weights without gradient descent.
- Read weight matrices as human-interpretable cards
- LLM-generated or analytical JSON patches
- A/B measured against untouched control twin
- Grounded in MIT-CSAIL interpretable RL research

### 2. **Autonomous Epistemology** (⭐⭐⭐⭐⭐)
Each agent builds its own science through axiom formation and testing.
- Writes IF-THEN axioms from observations
- Tests axioms against reality
- Undergoes paradigm shifts when falsified
- Personal skepticism thresholds

### 3. **Composable Verbs** (⭐⭐⭐⭐)
Learning through teaching and action composition.
- Verbs are learned, not hardcoded
- One agent teaches another
- Creates intergenerational knowledge transfer
- Enables creative action combinations

### 4. **Inner Monologue** (⭐⭐⭐⭐)
Streaming thoughts tied to emotional state.
- 8 distinct emotional state patterns
- Maps neural network state → natural language
- Bridges interpretability + immersion
- Grounded in affective computing & sentiment analysis

### 5. **Psi-Theta Dynamics** (⭐⭐⭐⭐)
Mathematical consciousness model.
- Five coupled differential equations (Ψ, θ, A, V, P)
- Combines neuroscience + RL + control theory
- Every emotion has a mathematical source
- Normalized to [0,1] for elegance

## 🔬 Technical Details

### Neural Network
- **Architecture:** 32→16→6 (input → hidden → output)
- **Input:** Emotional state, personality, health, social metrics, vitals (32 dims)
- **Output:** 6 action probabilities (speak, bonk, trade, wander, sleep, learn)
- **Training:** Experience replay with reward shaping
- **Interpretability:** Every weight readable and editable

### Emotional Model
```
Ψ = Core energy / existence drive
θ = Expectation / world model
A = Arousal / pain reactivity
V = Valence / emotional tone
P = Prediction error / surprise
```

Updated each tick by:
```
Ψ_t+1 = clip(Ψ_t + α(s_t - Ψ_t), 0, 1)
θ_t+1 = clip(θ_t + α(s_t - θ_t), 0, 1)
A_t+1 = clip(A_t + α(pain_t·10 - A_t), 0, 1)
V_t+1 = clip(V_t + α(s_t - V_t), 0, 1)
P_t+1 = clip(P_t + α(|s_t - θ_t| - P_t), 0, 1)
```

### Memory Systems
1. **Episodic Buffer:** 500 experiences, weighted by salience
2. **Experience Replay:** Trains neural network
3. **Conversation History:** Multi-turn dialogues with persistence
4. **Episodic Memory:** World events with emotional context
5. **Social Memory:** Relationships, grudges, crushes, rivals
