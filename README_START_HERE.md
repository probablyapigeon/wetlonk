## 🧪 If Something Breaks

### **Error: `ModuleNotFoundError`**
Make sure you're in the RIGHT directory:
```powershell
# Show current directory
Get-Location

# Should show C:\Users\kiers\xembra-xc\desktop-lonkworld (or your chosen system)
```

### **Error: Unicode/Emoji not displaying**
Make sure the FIRST line has the encoding:
```powershell
$env:PYTHONIOENCODING="utf-8" ; ...
```

### **Slow startup?**
First run takes 2-5 seconds (compiles XC bytecode). Subsequent runs are faster.

### **Can't see GUI?**
Try the CLI version instead:
```powershell
$env:PYTHONIOENCODING="utf-8" ; cd "C:\Users\kiers\xembra-xc\desktop-lonkworld" ; python xc_app_runtime.py --source LonkWorld.xc
```
