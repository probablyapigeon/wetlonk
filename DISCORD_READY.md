## If They Ask Follow-Up Questions

**"How realistic are the agents?"**  
They're not simulating real humans, but they do genuine learning and belief formation. They build worldviews from experience and abandon false beliefs when contradicted. That's not typical in game AI.

**"Can they teach each other?"**  
Yes. Skills (verbs) are learned and can be taught. One agent can learn something, then another agent can learn it from them. Knowledge spreads through the civilization.

**"What's the incomplete part?"**  
The spec language (XC) and world configuration file (LonkWorld.xc) exist and are good, but the engine doesn't read them yet. So you can't modify world parameters by editing a config file. The core systems work; the integration between spec and engine is the missing piece.

**"Does it call an API or need internet?"**  
No. Completely offline. 100% local computation. No external services. No tracking. Just Python + NumPy on your machine.

**"Is it open source?"**  
Yes. https://github.com/probablyapigeon/wetlonk MIT license.

**"Can I modify it?"**  
Absolutely. The engine code is Python, readable, and designed to be edited. You can hack on weights directly, change parameters in the code, run experiments.
