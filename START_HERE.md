## ⚠️ Troubleshooting

### **"Python not found"**
- Ensure Python 3.9+ is installed and in PATH
- Test: `python --version`

### **"Module not found" errors**
- xembra-xc and unified are self-contained
- Run from their respective directories
- All dependencies should already be installed

### **UTF-8 encoding issues**
- Always include: `$env:PYTHONIOENCODING="utf-8"` before running
- This fixes emoji/special character display

### **"Port already in use"** (xembra-xc only)
- Close any other xembra-xc instances
- Or wait 30 seconds and retry

### **System crashes or freezes**
- XEMBRA Terminal: Use `/silence` to pause autonomous thoughts
- Unified: Use `/quit` cleanly
- Creature: Type `quit`
- xembra-xc: Close window
